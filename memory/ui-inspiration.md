# Losey.Co UI/UX Inspiration: Motorsports & Automotive Restoration

This document extracts 'gold-standard' patterns from top-tier automotive and motorsports websites to inform the Losey.Co Template Library.

---

## 1. Singer Vehicle Design (singerdesign.com)
**Vibe:** Minimalist Luxury, Obsessive Craftsmanship.

### Layout Patterns for 'Project Showcases'
- **The "Philosophy First" Approach:** Hero sections lead with a mantra ("Definitive Design") rather than specs.
- **Zig-Zag Imagery:** Full-bleed carousels on one side with a quote or minimal text/heading on the other.
- **High-End Typography:** Use of serif headings with clean sans-serif body text, heavily centered or perfectly aligned on a strict grid.

### Interactive Elements
- **Smooth Image Carousels:** Large, high-resolution carousels with minimal navigation (just < > or simple dots).
- **Popup 'Connect':** A simplified "Connect" button that triggers a clean, high-contrast modal instead of a footer-buried form.

### Aesthetic Tokens
- **Palette:** Deep blacks, crisp whites, and gold/car-specific accent colors.
- **Grid:** Spacious gutters, allowing high-res photography to 'breathe'.
- **The Mantra:** "Everything is Important" - Every UI element feels deliberate.

### The 'Hook'
- **"Inquire Now" CTA:** Always present but never intrusive.
- **Disclaimers:** Highly visible but integrated into the footer aesthetic to maintain brand integrity.

## 2. AMS Performance (amsperformance.com)
**Vibe:** Technical Excellence, Performance Engineering.

### Layout Patterns for 'Project Showcases'
- **Video-First Highlights:** Uses blog-style layouts where high-quality video content (e.g., "1,100whp Huracan STO") is the primary showcase.
- **Performance Grids:** Technical parts are displayed in a functional, clean grid with immediate "Buy Now" CTAs.

### Interactive Elements
- **Advanced Search/Configurator:** Focus on part compatibility and search by vehicle model.
- **Read More/Watch More CTAs:** Encourages deep-diving into the build process.

### Aesthetic Tokens
- **Palette:** Dark mode focus, using bright white backgrounds for product photos to make 'engineering art' pop.
- **Iconography:** Uses technical icons (turbos, gears) to categorize services.

### The 'Hook'
- **E-commerce Integration:** Blends custom build showcases with direct part sales.
- **"Dealership" Finder:** Interactive map to capture local leads.

## 3. Hennessey Performance (hennesseyperformance.com)
**Vibe:** Aggressive Power, American Performance.

### Layout Patterns for 'Project Showcases'
- **Stat-Heavy Cards:** Projects are introduced with "HP", "Torque", and "Warranty" as the primary descriptors.
- **Massive Asset Galleries:** Project pages feature 20+ photos, emphasizing the 'look' as much as the 'go'.

### Interactive Elements
- **Sticky Metric Bars:** Performance stats that remain visible or prominent during scrolling.

### Aesthetic Tokens
- **Typography:** Bold, aggressive, uppercase headings ("THE AMERICAN DREAM NEVER SLEEPS").
- **Palette:** Red, White, Black (Patriotic/Bold contrast).

### The 'Hook'
- **Warranty-as-a-Feature:** Using "3 Year / 36,000 Mile Limited Warranty" as a primary CTA/lead capture tool to build trust in high-output builds.

---

## 4. Formula 1 (f1.com)
**Vibe:** Data-Driven Speed, Modern Precision.

### Layout Patterns for 'Project Showcases' (Results/Viz)
- **Dense Data Tables:** Highly readable, color-coded tables for race results.
- **Event Trackers:** Live-updating session status and 'track time' vs 'local time' widgets.

### Interactive Elements
- **Tabbed Results:** Seamless switching between Races, Drivers, and Teams without page reloads.
- **Dynamic 'Display Mode':** User-controlled dark/light mode or density settings.

### Aesthetic Tokens
- **Brand Colors:** Utilizing team colors (McLaren Papaya, Ferrari Red) as UI accents to provide immediate context.
- **Speed Graphics:** Italicized fonts and sharp, angled UI components to convey momentum.

### The 'Hook'
- **Subscription Model:** "F1 TV" and "Member's Area" (Unlocked) are the primary capture points.
- **Partner Integration:** Sponsor logos are treated as part of the visual grid, not just 'ads'.

## Losey.Co 'Gold Standard' Synthesis

| Feature | Pattern Recommendation |
| :--- | :--- |
| **Hero Section** | High-impact philosophy statement + Minimal Spec Card (Singer/Hennessey mix). |
| **Showcase** | Zig-zag layout with full-bleed carousels and technical 'Stat Overlays'. |
| **Lead Capture** | "Inquire for Build" sticky button + "Warranty/Reliability" trust badge. |
| **Data Viz** | Interactive performance graphs (HP/Torque curves) using F1-style precision. |
| **Aesthetics** | Dark mode by default, high-contrast, bold typography, team-specific accent colors. |
